Incus 2.0.0

- 节点软件包统一命名为 incus，连接器为 incus-agent；上游 Incus 保持正式 7.0.2 LTS 基线。
- 节点目录、服务、API、认证头及内核对象统一使用 Incus 命名。节点连接器安装在 /usr/libexec/incus/agent/incus-agent，上游来宾代理保留原路径。
- 发行包的文档目录只保留必要版权与许可证，不安装项目开发文档或二开说明。
- 本机管理状态和审计事件采用 AES-256-GCM 加密，损坏、缺失密钥和异常权限会拒绝操作。
- 提供离线升级入口：先 dry-run，再停机、执行目标版本迁移脚本、安装并恢复服务。
- 保留节点存储管理、启动恢复、TUI、出口代理及实例动态出口策略功能。

安装与配套要求

本版采用新节点布局和新面板协议，需要配套更新控制端。旧平台命名布局到本版的一次性迁移脚本尚未提供；已有旧布局节点应先准备并审查离线迁移脚本，不能直接将本发行包作为原地升级方案。

支持 Debian 13、Ubuntu 24.04、Ubuntu 26.04，均提供 amd64 和 arm64 软件包及逐平台 SHA256SUMS。
