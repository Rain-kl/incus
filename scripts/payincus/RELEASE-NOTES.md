集成预发布版本，基于 Incus 7.0.2 LTS。

- 包含定制 incusd、CLI、官方 VM Guest Agent、受限用户服务、精简宿主连接 Agent 和网络恢复工具。
- 节点扩展通过 /1.0/payincus 提供，沿用 Incus 认证授权。控制端支持新旧节点协议。
- 提供 amd64/arm64 原生 Ubuntu 24.04 构建的 deb 与归档、源码提交/上游基线清单及 SHA256 校验。
- 发布不等于生产验收；首次安装后需配置 Incus 存储/网络、面板凭据和 mTLS 信任。
- 软件包不会自动启动、重启或启用服务；升级现有节点前应安排维护窗口并检查持久化网络保护。
- 完整接口、测试和限制见仓库 FEATURES.md。此版本不作为生产稳定版。
